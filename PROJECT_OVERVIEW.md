POUYANLY

Complete Product Development & Engineering Mission

1. Project Introduction

POUYANLY is a Persian-first, AI-assisted English-learning platform designed primarily for Persian-speaking learners.

The application is built with Flutter and Dart, with Android as the initial target platform.

POUYANLY aims to combine the strongest educational and user-experience concepts found in leading language-learning platforms, including Duolingo, Busuu, Babbel, Memrise, Anki and ELSA, while developing its own identity, educational methodology and technical architecture.

POUYANLY is not intended to be a simple vocabulary application or a collection of disconnected quizzes.

It must become a complete English-learning ecosystem that helps learners progress from CEFR A1 to C2 through structured lessons, contextual vocabulary, grammar, listening, speaking, reading, writing, intelligent revision, assessments and personalized learning.

2. Product Vision

Build a professional, reliable, visually distinctive and educationally effective application that:

- Teaches real English rather than merely rewarding repetitive interactions.
- Supports CEFR levels A1, A2, B1, B2, C1 and C2.
- Provides a structured and progressive learning journey.
- Adapts learning content to the learner's level and objectives.
- Provides high-quality Persian explanations.
- Uses English naturally in increasingly advanced levels.
- Works offline for its core educational features.
- Stores actual user progress reliably.
- Provides meaningful feedback for every mistake.
- Offers intelligent vocabulary revision.
- Uses gamification to improve consistency without replacing educational value.
- Has a modular architecture that can support future AI and cloud services.
- Is suitable for eventual public release.

3. Target Audience

Primary audience:
Persian-speaking learners studying English.

Initial platform:
Android.

Technology:
Flutter and Dart.

Primary interface language:
Persian (RTL).

Learning language:
English.

Educational framework:
CEFR A1–C2.

Initial distribution:
Installable Android APK.

Long-term possibilities:
Cloud synchronization, AI tutoring, website, subscription services and additional platforms.

4. Core Product Principles

1. Educational accuracy comes before visual decoration.
2. Real learning comes before XP and gamification.
3. Every incorrect answer should produce useful educational feedback.
4. Vocabulary must be taught in context.
5. No fake progress, fake statistics or simulated functionality.
6. No placeholder buttons presented as completed features.
7. No fabricated dictionary entries, IPA transcriptions or educational content.
8. Every learning stage must have measurable completion criteria.
9. Offline functionality must be preserved.
10. Every feature must be tested before being considered complete.
11. Persian RTL must be implemented correctly throughout the application.
12. The application must remain maintainable and scalable.

5. Definition of Success

POUYANLY is successful only when its core features work together as one coherent product.

A visually attractive screen with broken functionality is not complete.

A working feature with unreliable educational content is not complete.

A successful implementation must satisfy functionality, educational quality, visual quality, data integrity, accessibility, performance and testing requirements.
